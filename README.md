# CZB Chain Risk Verification Tools

Defensive tools, templates, and documentation for read-only chain risk verification.

This repository collects the safer public side of CZB Security Lab's tool surface: BTC/LTC address query helpers, risk-review templates, assessment-center records, and wallet exposure audit guidance.

## What This Repository Covers

- BTC and LTC public address query workflow
- Address and transaction evidence organization
- Risk verification checklist templates
- Public assessment report structure
- Wallet exposure audit guidance that avoids private keys, seed phrases, and credential handling

## Safety Boundary

This repository does not collect, request, store, or process seed phrases, private keys, wallet backup files, exchange passwords, or signing credentials. It is designed for defensive review using public addresses, public transaction hashes, and user-redacted evidence.
