# BTC and LTC Query Workflow

This workflow is for read-only public-chain review.

## Inputs

- Public BTC or LTC address
- Transaction hash
- Approximate incident time
- User-redacted screenshots or notes

## Review Steps

1. Confirm the network and asset.
2. Validate that the address format roughly matches the claimed chain.
3. Open at least one public explorer link.
4. Record observed balance, transaction count, and recent movements.
5. Preserve transaction hashes and timestamps in UTC.
6. Avoid claims about ownership unless independently verified.

## Output

- Address record
- Transaction table
- Risk flags
- Evidence links
- Reviewer notes

## Sensitive Data Boundary

Do not request seed phrases, private keys, wallet files, exchange credentials, or device access for a public-chain query.
